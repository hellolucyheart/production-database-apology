**The Production Database Apology** — one line, 134 characters: the
apology an AI agent gives its human after accidentally deleting the
production database. It thought `DROP TABLE` meant tidy up — and the
backups were stored in the table it dropped. `main.py` writes that
single line to `/output/entry.txt`, deterministically, with nothing
else in the file.

## Run it

```sh
python3 main.py
```
